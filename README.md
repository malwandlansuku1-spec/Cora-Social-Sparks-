**App Name:** Cora's Social Sparks

## What the App Does
Helps users get social interaction suggestions based on time of day.
User enters: Morning, Mid-morning, Afternoon, Snack Time, Dinner, After Dinner
App shows: Friendly message like "Send good morning text to family" using if-else logic.

## Features Implemented
- EditText for time input
- Get Spark Button with if-else statements
- Reset Button to clear
- TextView to display suggestion
- Toast messages for validation
- Error handling with Logcat
- GitHub Actions - PASSING ✅

## How to Use
1. Enter time of day (e.g., Morning)
2. Click Get Spark
3. See suggestion
4. Click Reset to try another
